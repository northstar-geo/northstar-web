# 第三方来源与复用记录

以 `package-lock.json` 为确切依赖版本权威。本次直接使用：

| 组件 | 版本 | 许可 | 用途与边界 |
| --- | --- | --- | --- |
| Next.js（网站框架） | 16.3.6 | MIT | 原生路由、服务端渲染与元数据；无外部托管绑定 |
| React（界面库） | 19.2.4 | MIT | 页面组件 |
| Tailwind CSS（样式工具） | 4.3.2 | MIT | 现有样式基础 |
| fflate（压缩库） | 0.8.3 | MIT | 仅导入时读取官方压缩包 |
| tsx（类型脚本运行工具） | 4.23.15 | MIT | 脚本与领域测试 |
| Playwright（浏览器测试工具） | 1.63.0 | Apache-2.0 | 本地浏览器验证 |
| axe-core（可访问性工具） | 由锁文件确定 | MPL-2.0 | 本地可访问性检测 |

来源为各软件的官方 npm（包管理器）发布与包内许可证；没有复制修改这些软件。升级在当前兼容主版本内执行，回退通过审查分支及锁文件；不将第三方工具变成公司任务或权限权威。

数据许可单独维护于 `data/sources.json`，下载证据维护于 `data/import-receipt.json`。使用美国人口普查局公开统计数据及地理名录，保留来源与计算归属；不使用其图像、标识或受限制微观记录。

统计上下限依据 [Census 2024 统计编码说明](https://www2.census.gov/programs-surveys/acs/tech_docs/jam_values/2024_Jam_Values.xlsx) 与实际表文件核对。按表识别上下限、保留原始编码，不把人口计数误当中位数封顶；租金上限编码 3501 对应至少 3,500 美元。

MapLibre（开放地图渲染器）候选参考：`https://maplibre.org/maplibre-gl-js/docs/`。当前只有参考点，无瓦片与多边形输入，故首版使用原生矢量定位图；未来地图渲染器可以替换，数据模型无需改变。

工作包所列竞争网站只作为产品模式输入，不是数据库来源。不建立商业地图、地址验证或数据供应商账号。
