# 当前产品定位

Northstar（北极星产品）旗下 Zipora（邮编地理智能产品）首版提供来源透明的地理智能：让用户搜索地区、理解人口与住房背景、比较地区，并核查每项数据的来源与统计期。

以搜索为首页中心，以真实公开统计数据构建独立页面价值。不提供无依据的宜居评分，不用自动生成的填充文章替代数据。邮政编码、统计区域和行政区域在领域模型中分开。

本次只建设美国网站生产前版本；公开开发者接口、会员、移动应用、完整智能助手、国际扩展、加密支付不在首版范围。

用户需求与商业化假设仍需真实使用验证；工程完成不代表获客或收入模型已验证。后续商业决策由产品核心对话与创始人负责。
