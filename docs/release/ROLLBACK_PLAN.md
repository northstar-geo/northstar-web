上列产品基线是原项目历史审查输入，不是当前 OKELOM 云平台候选，也未验证为云平台可回滚产物。当前精确候选、真实预览及回滚状态以[持续计划](../superpowers/plans/2026-10-09-okelom-preview-readiness.md)为准。不得将浮动 `develop` 分支或未适配旧提交用作回滚目标。

获授权的发布负责人必须在实际部署记录中绑定：完整提交哈希、数据快照哈希、构建产物摘要、部署标识、构建与运行配置、访问保护状态，以及实际验证过的撤回目标。首次发布仍以撤回公开流量为安全后备，不凭空指定一个从未部署的“上一版本”。预览执行者须先提供撤回/恢复演练结果，再申请最终发布门禁；本文不预填不存在的部署标识。

## 发生严重问题时

1. 由获授权的发布负责人撤回当前部署流量或禁用部署；不要在现场修改代码。
2. 保持 `INDEXING_ENABLED=false`，撤回或禁止公开索引，并确认 `/robots.txt` 状态。
3. 对首次发布，恢复到无公开生产目标；对后续发布，只恢复到已审查的精确提交与对应快照。
4. 验证首页、搜索、ZCTA、州、比较、错误页、数据哈希、5xx（服务器错误）和访问限制。
5. 记录时间、影响、精确构建／快照、采取的撤回动作和后续修复；不得把用户查询或凭据写入事件记录。

本计划不授予任何部署、DNS（域名系统）或索引操作权限。
