# 首次生产发布回滚计划

## 固定输入

`REVIEWED_PRODUCT_BASELINE = 0b589e79997a8c9c1735b3d82ed66d82e8d47f84`  
`DATA_SNAPSHOT_SHA256 = 2e100f671f3a84997b30627ababbfc94e049f7c2d2cf8d328c42c6006a2778c5`  
`PREVIOUS_PRODUCTION_TARGET = NONE_FIRST_LAUNCH`

不得将浮动 `develop` 分支用作回滚目标。实际生产候选在最终发布门禁时必须以精确提交哈希、构建标识和上列数据快照哈希再次写入部署记录。

## 发生严重问题时

1. 由获授权的发布负责人撤回当前部署流量或禁用部署；不要在现场修改代码。
2. 保持 `INDEXING_ENABLED=false`，撤回或禁止公开索引，并确认 `/robots.txt` 状态。
3. 对首次发布，恢复到无公开生产目标；对后续发布，只恢复到已审查的精确提交与对应快照。
4. 验证首页、搜索、ZCTA、州、比较、错误页、数据哈希、5xx（服务器错误）和访问限制。
5. 记录时间、影响、精确构建／快照、采取的撤回动作和后续修复；不得把用户查询或凭据写入事件记录。

本计划不授予任何部署、DNS（域名系统）或索引操作权限。
