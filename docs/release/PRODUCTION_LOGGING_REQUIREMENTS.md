# 生产日志要求

当前应用只通过 Next.js（网站框架）服务器端 `onRequestError` 记录最小诊断事件：错误类型、框架摘要、HTTP（超文本传输协议）方法、路由模板与处理类型。它不会记录请求路径、查询参数、请求头、错误消息或堆栈。

选定托管平台前，必须确认并记录：

- 5xx（服务器错误）、崩溃、内存耗尽、启动失败和部署失败的可见诊断来源；
- 谁有日志访问权、提供方实际保留期、删除流程和事件升级联系人；
- 访问日志可能包含完整路径或查询参数，因此不得将其导出、粘贴到工单或用于分析，除非获得单独的隐私审查；
- 应用不得把用户搜索、凭据、Cookie（浏览器标识）或密钥写入自定义日志。

`ERROR_OBSERVABILITY_STATUS = APPLICATION_MINIMAL_EVENTS_READY; HOSTING_PROVIDER_POLICY_PENDING`

本项目未接入第三方错误监控、分析或付费可观测性服务。
