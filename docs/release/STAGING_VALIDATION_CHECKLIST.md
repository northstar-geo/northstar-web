# 预发布验证清单

执行者在未来获授权的托管环境中逐项记录日期、环境与结果；本文件目前不是已完成证明。

- [ ] 预发布部署使用精确代码提交和已验证数据快照。
- [ ] `SITE_URL` 由环境注入，格式为单一 HTTPS 源站，无路径、查询、凭据或片段。
- [ ] 构建及运行均为 `RELEASE_STAGE=preview`、`INDEXING_ENABLED=false`，`/robots.txt` 禁止抓取，预发布未对公众开放。
- [ ] 首页、搜索、统计邮编区域、州、城市、县、比较、方法、数据来源、关于和 404（未找到）页面可访问。
- [ ] 规范网址、Open Graph（开放图谱）使用同一 HTTPS 源站；全部预览页面为 `noindex, nofollow`，无结构化数据，站点地图索引不列公开条目。
- [ ] 未认证访问页面、分享图、图标、框架静态文件及 `/_geo/` 分片均被拒绝；认证后的直接资产响应也带禁止索引头，不能以应用响应头替代平台访问保护。
- [ ] 区分不存在的路由（非流式HTTP 404）与缺失地理实体的流式缺失页（框架可能返回200）；两者均显示正确缺失提示、禁止索引、无虚构数据，且能恢复搜索和比较。不把状态200单独当作页面可用证明。
- [ ] 数据文件哈希、启动、5xx（服务器错误）、错误页与访问保护经实际环境验证。
- [ ] 浏览器、容量和实验室网页指标结果已链接，且未将其表述为真实用户或真实设备数据；覆盖键盘、320px小屏、768px平板、暗色、长内容、错误恢复、代表链接和失败资产。
- [ ] 对完整响应、预取取消和页面切换分别采集运行证据；确认没有未完成的真实用户请求、5xx或 hydration（客户端激活）错误。不得按错误文本全局屏蔽服务端日志。
- [ ] 发布负责人提供精确部署标识、候选提交与产物/快照摘要及受保护预览的撤回/恢复演练结果，依[回滚计划](ROLLBACK_PLAN.md)记录，不使用浮动分支。

完成预发布验证不等于生产部署、公开索引或公开发布授权。
