# 隐私、关于与支持准备

## 当前应用事实

- 搜索和比较值可出现在 URL（统一资源定位符）的查询参数中；应用本身不持久化这些查询。
- 未来托管商、CDN（内容分发网络）或访问日志可能记录请求路径；实际收集、保留、地域和访问权限取决于尚未选择的提供方。
- 当前没有账号、广告、支付、产品分析或第三方跟踪脚本。
- 关于页和方法页说明 Census（美国人口普查局）数据边界、ZIP（邮政编码）与 ZCTA（人口普查邮编统计区）差异及首版限制。

## 发布前待完成项

`SUPPORT_CONTACT_STATUS = PENDING_FOUNDER_INPUT`

在 Founder（创始人）提供可公开的支持联系方式并选定托管商前，不得声明具体日志保留期限、服务响应时间、数据删除期限或隐私政策条款。公开发布前需将经过批准的联系渠道、托管日志事实、版本日期和适用范围写入关于／隐私说明。
