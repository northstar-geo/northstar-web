## 架构与复用判断

复用现有网站框架和页面组件；使用框架原生服务端页面、元数据与路由。地理查询模块独立于页面；首版采用本地版本化快照，运行时不请求供应商，不要求外部数据库账号。数据库迁移用于本地 SQLite（嵌入式数据库）适配，未来可替换存储。

复用美国人口普查局官方数据，不抓取竞争对手数据库。邮政编码与人口普查统计区域分开建模；没有邮政权威数据时不推导投递有效性、不伪造邮政映射。地图数据与渲染独立；评估 MapLibre（开放地图渲染器），无瓦片供应商授权时优先本地几何绘制。

公司执行、权限、路由、记忆与回执基础设施不在本项目内建设；后置接入遵守中央引用。
