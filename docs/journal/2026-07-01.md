# Problems Encountered

### Git Push

Cursor did not clearly display the Push button.

### Solution

Used Git command line instead.

```bash
git push -u origin develop
```

This successfully created and linked the remote `develop` branch.

---

# Decisions Made

The project will follow a professional Git workflow.

Branch strategy:

```

```

Future features may use:


before merging into `develop`.
